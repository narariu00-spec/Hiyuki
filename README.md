# Hiyuki - Wuthering Waves Theme

Welcome to the **Hiyuki** MIUI Theme repository! This is a premium theme inspired by the popular game **Wuthering Waves**.

## 🎨 Theme Overview

Hiyuki is a modern, sleek MIUI theme that brings the sci-fi aesthetic and cool color palette of Wuthering Waves to your Android device. Perfect for fans of the game and those who love futuristic, minimalist design.

## ✨ Features

- **Beautiful Lockscreen Design**: Immersive lockscreen with smooth animations
- **Modern Icons**: Custom-designed app icons inspired by Wuthering Waves
- **Sci-Fi Wallpapers**: Stunning wallpapers with futuristic aesthetic
- **Smooth Animations**: Fluid transitions and interactive elements
- **Minimalist UI**: Clean and elegant user interface
- **Multi-Language Support**: English and Chinese support

## 📱 Compatibility

- **Device**: Xiaomi devices with MIUI 12 or higher
- **Format**: .mtz (MIUI Theme Package)

## 🎮 Inspiration

This theme draws inspiration from **Wuthering Waves**, a popular sci-fi action RPG known for its:
- Cyberpunk and futuristic aesthetics
- Cool color schemes (blues, purples, cyans)
- Modern and sleek visual design
- Immersive world-building

## 📦 Installation

1. Download the `.mtz` file
2. Open MIUI Theme Manager
3. Select "Install" and choose the downloaded file
4. Apply the theme to customize your device

## 🛠️ Theme Contents

- `description.xml` - Theme metadata and descriptions
- `lockscreen/` - Lockscreen assets
- `icons/` - Custom app icons
- `framework-res/` - System UI elements
- Wallpapers and additional resources
